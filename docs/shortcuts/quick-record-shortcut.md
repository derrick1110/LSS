# 极简记账快捷指令配置

## 目标

创建一个快捷指令：触发后输入消费金额，然后打开极简记账并自动新增一笔餐饮支出。

## 快捷指令步骤

1. 打开 iPhone 的“快捷指令”App。
2. 新建快捷指令，命名为“极简记账”。
3. 添加动作“询问输入”。
   - 提示文字：`本次消费金额`
   - 输入类型：`数字`
4. 添加动作“URL”。
   - URL 内容填：

```text
jijianbook://record?amount=快捷指令输入
```

5. 添加动作“打开 URL”。
6. 运行快捷指令，输入例如 `12.5`。
7. App 应自动打开，并在今日页新增一笔餐饮支出。

## 建议入口

- 放到主屏幕。
- 放到锁屏小组件。
- 放到控制中心。

## 可选分类 URL

MVP 默认分类是餐饮。如需测试其他分类，可以手动改 URL：

```text
jijianbook://record?amount=12.5&category=daily
jijianbook://record?amount=12.5&category=other
```

分类参数：

- `food`：餐饮
- `daily`：日用
- `other`：其他

## 异常行为

- 金额为空：打开 App 补记页，不新增记录。
- 金额不是数字：打开 App 补记页，并提示金额格式不正确。
- 金额小于等于 0：打开 App 补记页，并提示金额必须大于 0。
- 分类参数非法：仍然新增记录，分类按餐饮处理。
